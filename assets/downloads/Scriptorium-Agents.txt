# Scriptorium installation instructions for agents

Project page: https://williamliaw.com/scriptorium
Configuration ZIP: https://williamliaw.com/assets/downloads/Scriptorium.zip

Use these instructions when the user asks you to install or configure Scriptorium.

## Install

1. Identify the user's operating system and the machine on which they want Obsidian installed.
2. Download the matching installer as a file and inspect it before running it.
   Windows: https://williamliaw.com/assets/downloads/Install-Scriptorium-Windows.cmd
   macOS: https://williamliaw.com/assets/downloads/Install-Scriptorium-macOS.command
   Linux: https://williamliaw.com/assets/downloads/Install-Scriptorium-Linux.sh
3. Run the downloaded file in an interactive terminal.
   Windows: run the .cmd file.
   macOS: bash /path/to/Install-Scriptorium-macOS.command
   Linux: bash /path/to/Install-Scriptorium-Linux.sh
4. Supply an absolute path for a NEW vault folder, or press Enter for Documents/Scriptorium.
   The installer refuses an existing destination. For an existing vault (or a folder of notes), use
   https://williamliaw.com/assets/downloads/Setup-Scriptorium-Vault.py instead:
   python3 Setup-Scriptorium-Vault.py /path/to/vault --dry-run   (lists what it would change)
   python3 Setup-Scriptorium-Vault.py /path/to/vault --yes       (does it)
   It writes only inside the vault's .obsidian folder, merges the user's settings, never touches a note,
   and first copies .obsidian to .obsidian/scriptorium-backup-<date>-<time>. On Windows, Scriptorium-Setup.exe
   does the same ("Set up", or --setup-plan / --setup-only <folder>). In Obsidian, a Scriptorium vault has the
   command "Scriptorium: Set up another vault".
5. The installer detects Obsidian and installs it when missing. It verifies the configuration
   archive and official Obsidian download with SHA-256.
   Since 1.2.1 only a working Obsidian counts as installed: what an uninstalled Obsidian leaves behind
   (its obsidian:// link, an app in the Trash, an empty AppImage) does not, and the installer says so
   plainly if Obsidian could not be installed.
   Windows uses the official per-user installer.
   macOS installs Obsidian.app in ~/Applications.
   Linux installs the official x86-64 or ARM64 AppImage in ~/Applications when needed.
   Linux requires curl and unzip, a graphical desktop, and AppImage runtime support.
6. The installers open the new vault in Obsidian with its community plugins on (Obsidian 1.12+, closed during install;
   they briefly turn on Obsidian's command-line interface to do it and restore that setting). Otherwise choose
   "Open folder as vault", select the printed vault path, and choose "Trust author and enable plugins".
   The installer opens the vault picker. Complete this step in Obsidian to register the new vault.
7. The installers detect and install missing EB Garamond and Cormorant Garamond font families
   for the current user, including roman and italic faces. Restart any running Obsidian windows.
   For manual ZIP setup, install the fonts from Google Fonts.
   https://fonts.google.com/specimen/EB+Garamond
   https://fonts.google.com/specimen/Cormorant+Garamond
8. Open "Lorem Ipsum" in Reading view. Enable the bundled community plugins in Obsidian
   to use the Scriptorium mode switch.

## Expected configuration

- Theme: Typewriter.
- Enabled CSS snippet: manuscript.
- Text size: 22 px. Both modes use 1.45 line spacing.
- Fancy mode defaults OFF. Keep this default unless the user requests otherwise.
- Regular section headings use EB Garamond with centered small caps.
- Drop caps default to the Yinit decorative initials (public domain), embedded in manuscript.css; no install needed.
  Settings > Scriptorium > Drop cap also offers Goudy Initialen, a plain capital, or none.
  It also lists sets of drop caps (Kanzlei, Deutsche Zierschrift, and picture initials from gwern.net) and the
  user's own (command "Scriptorium: Add a set of drop caps"). One note can have its own drop cap: the property
  dropcap: <name>, or the command "Scriptorium: Choose the drop cap for this note". Export to PDF keeps the
  title and the drop caps.
- Footnotes appear as numbered sidenotes in the right margin in Reading view when the pane is wide enough
  (Settings > Scriptorium > Marginalia); > [!margin] callouts become unnumbered margin notes.
- Callouts render as paper-and-ink admonitions. Clicking an image opens it in focus with its caption
  (Settings > Scriptorium > Image focus).
- Images are centred by default; ![[image.png|left|300]], |right or |center places one (left/right float in Reading view).
- Links use rubric ink with a hand-drawn pen underline, matching williamliaw.com.
- Fancy section headings use Cormorant Garamond.
- Fancy mode uses borderless italic quotations and justified opening paragraphs.
- Regular mode uses bordered quotations and left-aligned opening paragraphs.
- Toggle using Settings > Scriptorium > Fancy mode, the feather ribbon icon,
  the status bar, or the command "Scriptorium: Toggle fancy mode".
- Bundled community plugins: Scriptorium, Lagrange, Longform, Manuscriptum, Typewriter Mode.
- Lagrange is an optional writing companion. A message in its chat can edit the open note (each edit is written in
  by a pen and one undo takes a request's edits back; its panel has Undo, Redo and a rewind on each message); it
  also has the commands revise selection, proofread note and draw a drop cap. It needs a provider chosen in
  Settings > Lagrange: a Claude or ChatGPT subscription through Claude Code or Codex (desktop), an API key, a local
  OpenAI-compatible server, or the offline demo. Never enter keys or sign in on the user's behalf.
- Experimental: "Scriptorium: Back up this vault to Google Drive", "Sync now" and "Retrieve a vault from Google
  Drive" work through Claude Code and the Google Drive connector of the user's Claude account (the default), or,
  as a preview, through a Google sign-in of the user's own (Settings -> Scriptorium -> Connection; it needs a
  Google OAuth client ID of type "Desktop app", which the user makes; the README says how). A vault is retrieved
  the way it was backed up. Run them only when the user asks, never sign in on the user's behalf, and never create
  or enter a client ID or secret for them. "Scriptorium: Copy the Google Drive diagnostic report" gives a report
  without secrets or file names when something fails.
- Main settings live in .obsidian/appearance.json and .obsidian/app.json.
- Typography lives in .obsidian/snippets/manuscript.css.
- The toggle plugin lives in .obsidian/plugins/scriptorium/.
- Its data.json stores fancyMode and the drop-cap, marginalia and image-focus settings.

## Writing conventions

The filename supplies the note title.
###### Subtitle
## Chapter heading
### Section heading
> *Italic quotation*
---
A horizontal rule becomes an ornamental scene break in Reading view.

## Verify

Check the actual Obsidian app with the intended fonts installed. Confirm the subtitle,
drop cap, quotation, section headings, and ornamental separator render in Reading view.
Toggle Fancy mode and confirm paragraph line spacing stays the same. Restore the user's
selected mode after testing. Capture screenshots from Obsidian when demonstrating it.

Report any platform-specific steps you could not test. Windows and macOS installers
have not yet received native end-to-end testing.
