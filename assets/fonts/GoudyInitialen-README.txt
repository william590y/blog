GoudyInitialen-Scriptorium.woff2: Goudy Initialen (A-Z), floriated initials after F. W. Goudy (Lanston Goudy
Initials No. 296), digitised by Dieter Steffmann. Converted to OpenType/WOFF2 from GoudyIn.pfb in the CTAN package
"initials" (https://ctan.org/pkg/initials), which the author released under the LaTeX Project Public License.
The site icon (favicon.svg) is the W from the same font.
