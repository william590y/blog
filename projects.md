## Obsidian configuration

A fancy and sophisticated obsidian configuration for the typographically inclined

Bookish serif typography, warm paper, centered small-cap headings, italic subtitles, drop caps, and ornamental scene breaks. Includes the Typewriter theme, a custom manuscript stylesheet, and writing plugins.

<a href="{{ '/assets/downloads/Writing-obsidian-config.zip' | relative_url }}" download>Download the Obsidian configuration</a>

### Easy setup

Download the installer for your operating system. It creates a new vault with the configuration and a Lorem Ipsum demonstration, then opens it in Obsidian. Existing vaults are preserved.

- <a href="{{ '/assets/downloads/Install-Writing-Windows.cmd' | relative_url }}" download>Windows installer</a> — open the downloaded `.cmd` file.
- <a href="{{ '/assets/downloads/Install-Writing-macOS.command' | relative_url }}" download>macOS installer</a> — run `bash ~/Downloads/Install-Writing-macOS.command` in Terminal.
- <a href="{{ '/assets/downloads/Install-Writing-Linux.sh' | relative_url }}" download>Linux installer</a> — run `bash ~/Downloads/Install-Writing-Linux.sh` in Terminal. Requires `curl` and `unzip`.

If Obsidian is missing, the installer opens its official download page. Install it, then open the new vault folder. Install **EB Garamond** and **Cormorant Garamond** for the intended fonts.

### Manual setup

The download includes a Lorem Ipsum sample with a title, subtitle, quotation, and headers. Extract the ZIP and open its folder as a vault in Obsidian. Install **EB Garamond** and **Cormorant Garamond** for the intended typography, then open **Lorem Ipsum** in Reading view. Setup instructions are included.
